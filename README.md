# Проверка скорости скачивания

Консольный скрипт на Python, который **10 раз последовательно** скачивает файл по указанной ссылке. Каждый новый запрос начинается только после полного получения предыдущего ответа. Скрипт показывает среднее время запроса, общий объём скачанных данных и среднюю скорость скачивания.

## Требования

- Python 3.9 или новее
- Доступ к указанному HTTP(S)-адресу
- Сторонние библиотеки не нужны

## Запуск

Откройте терминал в папке проекта и выполните:

```bash
python3 speed_test.py "https://example.com/large-file.jpg"
```

Замените пример ссылки реальным адресом достаточно большого файла. В Windows вместо `python3` можно использовать `python`.

Для подсказки по аргументам:

```bash
python3 speed_test.py --help
```

Таймаут одного запроса — 30 секунд. Если какой-либо запрос завершится ошибкой, скрипт сообщит её номер и причину, затем завершится с кодом `1`, не выводя неполный результат как успешный.

## Пример вывода

```text
Запрос 1/10: 1000000 байт за 0.420 с
...
Запрос 10/10: 1000000 байт за 0.390 с

Среднее время запроса: 0.405 с
Всего скачано: 10000000 байт (10.00 МБ)
Средняя скорость скачивания: 197.53 Мбит/с
```

Числа приведены для примера.

## Единицы измерения и расчёт

- **Время запроса:** секунды (`с`) — от начала открытия ссылки до полного чтения ответа.
- **Объём скачанных данных:** байты и десятичные мегабайты (`МБ`); 1 МБ = 1 000 000 байт.
- **Скорость скачивания:** мегабиты в секунду (`Мбит/с`); 1 Мбит/с = 1 000 000 бит/с, 1 байт = 8 бит.
- **Среднее время запроса:** сумма длительностей 10 запросов / 10.
- **Средняя скорость скачивания:** `(всего_байт × 8) / (суммарное_время_в_секундах × 1_000_000)`.

Ответ читается частями по 64 КиБ, суммарное количество байтов подсчитывается; файл на диск не сохраняется. Запросы выполняются последовательно. Время включает ожидание ответа сервера, поэтому результат отражает **скорость на уровне приложения**, а не точную пропускную способность интернет-канала. На результат могут влиять размер файла, сервер, кэширование и состояние сети.
